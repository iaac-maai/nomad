# Regulation PDFs

Put the PDF of **Decret 141/2012** (condicions mínimes d'habitabilitat dels habitatges i la cèdula
d'habitabilitat, Generalitat de Catalunya) here and name it `decret_141_2012.pdf`.

- Best: the official Catalan text from the DOGC / Portal Jurídic de Catalunya (search "Decret 141/2012").
- Check that the PDF has real text: open it and select a sentence with the mouse. If you cannot,
  it is a scanned image and the scripts cannot read it.
- Some copies online have broken letters ("supericie" instead of "superficie"). Then quotes will not
  match and grounding scores drop. Use the cleanest copy you can find.

Note for later: Annex 1 holds the values for new dwellings. A change of use (factory -> housing) is
covered in Annex 4 (rehabilitation), which applies Annex 1 with some exceptions. Version 1 of our
questions covers Annex 1; version 2 adds the Annex 4 exceptions.
