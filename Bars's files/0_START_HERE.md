# Bars's files

This folder contains Bars's work arranged in the team's numbered layout. Each step README explains its input, code,
output, and users. The previous Bars website is in `app/`; Bhavini's `app/` remains the official site.

- `2_building/`: Catastro transformations.
- `4_laws_and_rules/`: checked rule cards and law references.
- `5_daylight/`: daylight simulations and archived results.
- `6_check_the_shop/`: Annex 4 groups.
- `8_report_and_city/`: city district and dashboard outputs.
- `app/`: Bars's previous, self-contained site.
- `docs/`: method, cleanup history, and legal notes.
- `lab_book/`: experiments retained for reference.
- `rhino_grasshopper/`: Grasshopper and Rhino files.
- `tools/`: one-time setup utility.
- `private/`: local licensed or personal data; git-ignored.

Run `python serve.py --site bars` for this site or `python serve.py --site bhavini` for the official site.
